# 字母探险家 · 电视遥控器闯关版 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 alpha-explorer 改成一个 3–4 岁孩子能在 OPPO 电视(Chrome 66 WebView,kidbox 外壳)上只用遥控器玩的三阶段闯关(巩固字母 → 字母发音 → CVC 拼读)。

**Architecture:** 所有可测试的规则(出题、计星、解锁、方向选点、家长加法题、进度解析、音频清单)放在纯函数文件 `src/logic.js`,用 `node test.mjs` 测。Vue 视图只负责渲染和调用这些函数;`src/tv.js` 管遥控器方向键和焦点,`src/audio.js` 管音频播放和合成音效。关卡由 `src/data/levels.json` 配置,一个 `LevelView` 按题型渲染。

**Tech Stack:** Vue 3.5 + vue-router 4 + Vite 5 + Tailwind 3(已安装);devDependency 新增 `kokoro-js`(离线 TTS);测试用 `node:assert`,不引入测试框架。

**Spec:** `docs/superpowers/specs/2026-10-22-tv-quest-design.md`

## Global Constraints

- 目标内核 Chrome 66:`build.target: 'chrome66'`、`build.cssTarget: 'chrome66'`
- 不用:flex 容器上的 `gap-*`(用 `space-x-*`/`space-y-*` 或 grid 的 gap)、`aspect-ratio`、`Array.prototype.flat/flatMap`、`Object.fromEntries`、`:focus-visible`(要用就同时写 `:focus` 兜底)
- emoji 一律 ≤ Emoji 11
- 不加新运行时依赖;只允许新增 devDependency `kokoro-js`
- 所有可操作元素是 `<button>` 或 `<a>`,不用带 `@click` 的 `<div>`
- 页面按 960×540 CSS 像素设计,答题页不出现滚动条
- 每关 8 道题;第一次就答对 ≥ 6 题才过关;6/7/8 → 1/2/3 星
- 家长关卡:连续答对 2 题,答错锁 60000 ms
- localStorage 键 `alpha_explorer_progress`,结构 `{ levels: { [id]: { stars, at } }, stickers: [id], allUnlocked: false }`(`allUnlocked` 是计划阶段补的字段,用于家长一键解锁)
- TTS 音色 `af_heart`,模型 `onnx-community/Kokoro-82M-v1.0-ONNX`,ffmpeg 转码 `-ac 1 -b:a 48k`
- 提交遵循全局 CLAUDE.md:`<type>(<scope>): <中文描述>`,直接在 main 上提交,提交前 `git status -sb`

## Review Focus

1. 刷新页面或从 kidbox 直接打开 `/level/xxx`(没有上一页历史)后按页面上的「返回」→ 应回到地图,不能让 WebView 直接退出 → Task 5 键盘走查脚本覆盖
2. 地址栏打开未解锁或不存在的关卡 id → 跳回地图,不报错、不白屏 → Task 2 测 `isUnlocked`,Task 5 走查覆盖
3. localStorage 里是坏 JSON 或旧格式 → 当作空进度,不崩 → Task 1 测 `parseProgress`
4. 音频文件缺失或加载失败 → 选项最多 1.5 秒后变为可选,孩子不会卡住 → Task 4 的 `playSeq` 超时,Task 5 走查覆盖(临时把一个音频路径改成 404 来测)
5. 题目播放期间按确认、按方向键 → 不算作答,焦点留在原来的按钮上,不会掉到 body → Task 5 走查断言 `activeElement`

  - `alphabet.json` 每项新增 `"phonicsText": string`、`"phonicsOk": true`,`audio.phonics` 改成 `/audio/phonics/<ID>.mp3`。X 的 phonicsText 读词尾音(box 里的 /ks/)
  - `cvc.json`:约 30 项 `{ "word": "cat", "emoji": "🐱", "zh": "猫" }`,单词都是辅音-元音-辅音的三字母词,五个短元音都有;emoji 互不相同,且 ≤ Emoji 11
  - `levels.json`:数组,元素 `{ "id", "stage": 1|2|3, "type", "letters"?: "ABC…", "words"?: ["cat",…], "sticker": emoji }`。`type` 取以下之一:`find-upper` `find-lower` `case-match` `next-letter`(阶段 1)、`sound-letter` `first-letter`(阶段 2)、`word-picture` `missing-vowel`(阶段 3)。阶段 1 有 8–10 关,阶段 2、3 各约 6 关;id 形如 `s1-01`,数组顺序就是解锁顺序;每关贴纸不同
  - `isUnlocked(levels, progress, index) -> boolean`:`index === 0`,或 `progress.allUnlocked`,或前一关 `stars >= 1` 时为 true
  - `makeLevel(level, alphabet, cvc, rand = Math.random) -> { warmup: Card[], questions: Question[] }`,`questions.length === 8`
    - `Card = { kind: 'letter', letter } | { kind: 'blend', word }`。阶段 1、2 的热身用本关的字母卡,阶段 3 用本关单词的拼读卡
    - `Question = { prompt: string[], show: object, options: { id, label }[], answer: id }`。`prompt` 是按顺序播放的音频路径:先固定提示语 `/audio/prompts/<key>.mp3`,再播目标音;`label` 是字母文字或 emoji;选项正好 3 个,互不相同,其中一个是 `answer`
    - 选项优先从本关的字母或单词里取,不够 3 个时从全部字母或单词里补
    - `next-letter`:目标字母在字母表中的位置 ≥ 2,`show.seq` 是目标前面的两个字母
    - `sound-letter`:只从 `phonicsOk` 为 true 的字母里出题
    - `missing-vowel`:`show` 是 `{ before, after, emoji }`,选项是包括正确元音在内的 3 个元音
  - 提示语的 key 和读法:`find`:"Find the letter"、`next`:"What comes next?"、`sound`:"Which letter makes this sound?"、`first`:"What letter does it start with?"、`picture`:"Which picture is it?"、`missing`:"Which letter is missing?"、`great`:"Great job!"、`again`:"Let's try again!"

**Interfaces:**

- 路由:`/` → Map,`/level/:id` → Level,`/stickers` → StickerWall,`/parent` → Parent,其余路径重定向到 `/`
- 各页面的「返回」按钮统一调用:`history.state && history.state.back ? router.back() : router.replace('/')`

**行为(实现者必须做到的):**
- **Map**:关卡按阶段分三行,每行可以折返;已解锁的关卡是 `<button>`,点了 `router.push('/level/'+id)`;未解锁的是 `disabled` 的按钮;第一个未过关但已解锁的关卡带 `data-autofocus`;已过关的显示星星。右上角放「贴纸墙」,左下角放一个小的「家长」按钮
- **Level**:进入时如果 id 不存在,或 `isUnlocked` 为 false,就 `router.replace('/')`。用 `makeLevel` 生成本关,分三段状态:
  - 热身卡:一屏一张卡。字母卡有三个按钮:字母名、发音、单词;拼读卡按确认后字母依次亮起,播放各字母发音,再读整个词。下方「下一张」带 `data-autofocus`,右上角有「跳过」
  - 答题:播 `prompt` 时把 `listening` 设为 true。这时选项用 `aria-disabled="true"`,**不用 `disabled` 属性**,这样焦点不会掉;点击直接忽略。答错时:`beep('no')`,该选项永久 `aria-disabled`,重读 prompt;同一题第二次错,高亮正确答案并播放目标音,然后自动进入下一题。答对时:`beep('ok')`,1 秒后进下一题。只有第一次就答对的题计入 `firstTry`。每次换题后调用 `focusMain()`
  - 结算:`stars = starsFor(firstTry)`,`saveResult(id, stars)`。过关:贴纸盖章动画 + 播 `prompts/great`,只有一个「回地图」按钮(`data-autofocus`)。没过关:播 `prompts/again`,两个按钮:「再来一次」(`data-autofocus`,原地重新 `makeLevel`)和「回地图」。不自动跳到下一关
- **StickerWall**:用 grid 排出每关的贴纸;已得到的显示 emoji,没得到的显示灰色「?」。只有一个「返回」按钮,带 `data-autofocus`
- **Parent**:先出 `mathGate`,4 个选项按钮。连续答对 2 题才进入;答错就 `cooldown(60000).fail()` 并显示倒计时,期间选项 `aria-disabled`。进入后显示:每关的星星数和过关日期,「解锁全部」(`unlockAll`),「清空进度」(第一次点按钮变成「再按一次确认」,第二次才执行 `reset`)
- 每一页都放在 960×540 的视口里,不出现滚动条;Map 是例外,可以纵向滚动
