# 字母探险家 (Alpha-Explorer)

这是一个专为3-6岁儿童设计的英文字母启蒙Web应用。它通过丰富的色彩、可爱的动画和互动游戏，帮助孩子们在轻松愉快的氛围中学习字母的认知、发音和书写。

## ✨ 核心功能 (Core Features)

*   🏝️ **字母学习岛 (Alphabet Island):** 在卡通地图上探索26个字母，学习每个字母的大小写、发音和关联单词。
*   ✍️ **笔顺描红 (Tracing Practice):** 通过有趣的动画引导，在屏幕上练习正确的字母书写笔顺。
*   🎮 **游戏乐园 (Game Park):** 内置多种小游戏（如字母捉迷藏、大小写配对），在玩乐中巩固知识。
*   🏆 **成就墙 (Achievement Wall):** 收集字母勋章和游戏奖杯，见证学习路上的每一步成长。

## 🛠️ 技术栈 (Tech Stack)

*   **前端框架:** Vue 3 (Composition API + `<script setup>`)
*   **构建工具:** Vite
*   **样式方案:** Tailwind CSS
*   **动画库:** GSAP

## 🚀 快速开始 (Getting Started)

```bash
# 克隆项目
# git clone <repository-url>
# cd alpha-explorer

# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

## 部署 (Deployment)

本项目设计为纯静态网站，可轻松部署在 [Cloudflare Pages](https://pages.cloudflare.com/) 或任何其他静态托管服务上。
